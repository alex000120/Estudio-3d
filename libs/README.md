# Librerías externas

Este proyecto usa **Three.js r128** cargado desde CDN:

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js"></script>
```

Si deseas usarlo de forma local (sin conexión a internet):
1. Descarga `three.min.js` desde: https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
2. Colócalo en esta carpeta `libs/`
3. Actualiza el `<script src>` en `index.html` a: `<script src="libs/three.min.js"></script>`
